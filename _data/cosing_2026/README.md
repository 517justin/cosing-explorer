## 為什麼需要這份資料

`_data/COSING_CAS.csv` 是 2019 快照，`Restriction` 欄只有引用代碼（如 `II/358`），**沒有條文**，無法回答「限制的是什麼、限量多少」。本目錄補上那一層。
